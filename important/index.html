Basic Information

This website was composed by Smitty and Logan, as our Frankenstein project. We dedicated many hours into creating this website, perzonalizing it to each character, and trying our best to make it look nice.
We hope you enjoy this website as much as we enjoyed making it!

Why did we choose to make a website?

We chose to create a website to be unique and and provide an engaging experience for users to learn about the characters of Gris Grimlys Frankenstein, which was composed
from the words of Mary Shellys original novel.

What was the process like?

We had to learn how to use HTML, a coding language that allows people to create web pages. We had a few issues with the website at first, but we figured
out what the issues were, and fixed them. Some may think that creating this website was challenging, but we found it to be quite simple, very rewarding and
an overall enjoyable experience.
